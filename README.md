# Аналіз архівних описів — 0.7-draft

Робочий комплект для багатозначної тематичної класифікації архівних описів:
ДАМО, фонд 230, описи 1–4, і ЦДІАК України, фонд 356. Скрипт читає
`input.xlsx`, перевіряє структуру даних, формує статистику, звіти, графіки,
службові CSV та окремі тематичні XLSX/CSV-вибірки.

Первинний `input.xlsx` скрипт не змінює. Тематичні книги є похідними
дослідницькими вибірками, а не новими архівними описами.

## Запуск у PyCharm Community Edition

1. Розпакуйте комплект в окрему папку, наприклад `D:\Python\archival_analysis`.
2. Покладіть актуальний `input.xlsx` поруч із `fond_analysis.py`.
3. Відкрийте `fond_analysis.py` у PyCharm і виберіть Python 3.12.
4. У вибраному інтерпретаторі мають бути `openpyxl`, `PyYAML` і
   `matplotlib`. За потреби встановіть їх через Python Interpreter у PyCharm
   або в терміналі:

```powershell
& "C:\Users\Admin\AppData\Local\Programs\Python\Python312\python.exe" -m pip install openpyxl pyyaml matplotlib
```

5. Натисніть Run. Шлях визначається від папки скрипта, тому Working directory
   PyCharm не впливає на пошук вхідного файла.

`requirements.txt` і `.bat` свідомо не включені. Підключення до Google або
інтернету для виконання аналізу не потрібне. Без `matplotlib` будуть створені
таблиці й звіти, але не графіки.

## Конфігураційна модель

Налаштування відокремлені від коду:

```text
config/
├── analysis.yaml
├── categories.yaml
└── sources.yaml
```

- `analysis.yaml` задає вхідний файл, папку результатів, контрольні межі років
  і параметри експорту;
- `sources.yaml` задає аркуші, архів, фонд, опис і мову;
- `categories.yaml` є єдиним переліком тематичних категорій для
  класифікації, статистики, графіків та експорту.

Категорія описується так:

```yaml
- id: healthcare
  label: "Охорона здоров’я і санітарія"
  macroblock: socioeconomic
  enabled: true
  export: "охорона_здоров’я.xlsx"
  dictionaries:
    uk: "dictionaries/socioeconomic/healthcare.yaml"
    ru: "dictionaries/ru/socioeconomic/healthcare.yaml"
```

Якщо додати нову категорію з двома словниками, її статистика й тематичний
файл з’являться автоматично. Якщо встановити `enabled: false`, категорія не
завантажується і в новому запуску її файл не створюється. Старі папки запусків
при цьому залишаються незмінними.

Кореневий `sources.yaml` та `dictionaries/categories.yaml` залишено як
довідкові файли попередньої версії. За наявності папки `config` скрипт читає
саме нову конфігурацію.

## Тематичні вибірки

Для кожної увімкненої категорії створюється окрема книга з аркушами
`Опис 1`, `Опис 2`, `Опис 3`, `Опис 4`, `ЦДІАК`. Зберігаються вихідні колонки
A–E, шапка кожного аркуша, первинні значення, порядок записів, стилі клітинок,
висоти рядків, ширини колонок і параметри перегляду. Структурні заголовки до
тематичних книг не додаються. Тематику зазначено в імені файла, тому структура
шапки залишається такою самою, як у `input.xlsx`.

Класифікація багатозначна: одна справа може бути присутня у кількох
тематичних книгах. Сума тематичних підрахунків тому може перевищувати загальну
кількість справ.

`некласифіковані.xlsx` містить усі змістові записи без предметної категорії,
включно з випадками, де знайдено лише контекст. Їхній точний поділ зберігається
в `classification_index.csv`:

- `subject_single` — одна предметна категорія;
- `subject_multilabel` — дві або більше предметних категорій;
- `context_only` — лише згадки осіб, посад чи установ;
- `unclassified` — не виявлено ані теми, ані контексту.

Поле `classification_confidence` є описом сили евристичного правила
(`strong`, `threshold`, `context_only`, `none`), а не статистичною
ймовірністю або експертною оцінкою.

## Службові записи

Позначки `ВИБУЛА`, `ВИБУЛИ`, `ВИБУЛО` та їхні міжлітерні варіанти,
заголовки років, загальні заголовки груп, записи про описи й нерозпізнані
структурні рядки не включаються до тематичних справ. Вони зберігаються у
`службові_записи.xlsx` і `service_records.csv`.

## Мови та словники

Мову словника задає аркуш у `config/sources.yaml`. Автоматичне визначення
мови є лише контрольним сигналом і не перемикає словник безконтрольно.
Заголовки не перекладаються.

«Охорона здоров’я і санітарія» виділена окремою категорією. Назва лікарні,
шпиталю, карантину або медичної посади сама по собі є контекстом. Для
предметної теми потрібна медична дія або зміст: лікування, санітарний нагляд,
епідемія, карантинні правила, відкриття, ремонт чи утримання лікувального
закладу, медична служба тощо.
