# Archival Description Analysis

Reproducible Python tools for quantitative and thematic analysis of archival descriptions.

[Українською](#українською) · [English](#english)

> **Статус проєкту:** початковий етап розроблення. Формат вхідних даних, програмні модулі та методика аналізу ще уточнюються. Поточний репозиторій не містить завершеної версії програми або повних масивів архівних даних.

## Українською

### Про проєкт

**Archival Description Analysis** — дослідницький програмний проєкт для відтворюваного кількісного та тематичного аналізу архівних описів засобами Python.

Основною одиницею аналізу є окремий запис архівного опису: заголовок справи, її шифр, крайні дати та інші доступні метадані. Програма не аналізує повні тексти архівних документів, якщо вони окремо не підготовлені та не передані їй як текстовий корпус.

Початковий сценарій використання пов’язаний із дослідженням документів канцелярії Миколаївського військового губернатора:

- Державний архів Миколаївської області, фонд 230;
- Центральний державний історичний архів України, м. Київ, фонд 356.

Надалі інструмент має бути придатним для опрацювання описів інших архівних фондів, представлених у форматах CSV або XLSX.

### Мета

Проєкт має забезпечити прозору й повторювану альтернативу ручним підрахункам та універсальним вебсервісам текстового аналізу. Усі етапи — від очищення даних до побудови таблиць і графіків — повинні бути зафіксовані в коді та доступні для перевірки.

Загальні ідеї частотного, контекстного й хронологічного аналізу, відомі за інструментами цифрової гуманітаристики, зокрема Voyant Tools, можуть використовуватися як методичні орієнтири. Програмний код цього проєкту розробляється самостійно й не містить коду Voyant Tools.

### Заплановані можливості

- імпорт даних із CSV та XLSX;
- перевірка обов’язкових полів, порожніх значень і дублікатів;
- нормалізація регістру, пробілів, розділових знаків та варіантів написання;
- налаштовувані списки стоп-слів;
- підрахунок загальної частоти слів і словосполучень;
- окремий підрахунок кількості заголовків, у яких трапляється термін;
- розрахунок частки таких заголовків у досліджуваному масиві;
- аналіз за роками, десятиліттями та заданими історичними періодами;
- пошук термінів у контексті;
- тематична класифікація за відкритими словниками категорій;
- порівняння кількох фондів або описів за зіставними періодами;
- експорт результатів у CSV/XLSX;
- створення графіків і таблиць, придатних для використання в науковій роботі;
- формування звіту з параметрами проведеного аналізу.

### Методологічні принципи

1. **Розмежування одиниць підрахунку.** Кількість уживань терміна не ототожнюється з кількістю справ. Один заголовок може містити те саме слово кілька разів.

2. **Реальна хронологія.** Динаміка визначається за роками та крайніми датами справ, а не за умовним поділом суцільного тексту на рівні сегменти.

3. **Прозора класифікація.** Тематичні категорії, словники й правила віднесення записів зберігаються у відкритих конфігураційних файлах.

4. **Збереження вихідних даних.** Нормалізований текст не замінює первинний заголовок справи. Обидва варіанти мають зберігатися для перевірки результатів.

5. **Відтворюваність.** Результат супроводжується відомостями про версію програми, використані параметри, словники та склад вхідного масиву.

6. **Обережна інтерпретація.** Частотність лексики характеризує зміст і структуру архівного опису, але сама по собі не доводить інтенсивність історичних процесів.

### Майбутній формат вхідних даних

Остаточну схему буде визначено після узгодження описів фондів 230 і 356. Попередньо один рядок таблиці відповідатиме одній справі та міститиме такі поля:

| Поле | Зміст |
|---|---|
| `archive` | Назва або скорочення архіву |
| `fond` | Номер фонду |
| `inventory` | Номер опису |
| `case` | Номер справи |
| `title` | Оригінальний заголовок справи |
| `start_year` | Початковий рік |
| `end_year` | Кінцевий рік |
| `notes` | Примітки, якщо вони наявні |

Назви й склад полів можуть змінитися після перевірки реальних таблиць. Для кожного оприлюдненого демонстраційного набору даних буде додано окремий опис.

## English

### About

**Archival Description Analysis** is a research software project for reproducible quantitative and thematic analysis of archival finding-aid records with Python.

The primary unit of analysis is an individual archival description record, including its title, reference code, dates, and available metadata. The software does not analyse the full text of archival documents unless a separate textual corpus is explicitly supplied.

The initial case study focuses on records of the Office of the Mykolaiv Military Governor preserved in:

- the State Archives of Mykolaiv Region, Fond 230;
- the Central State Historical Archives of Ukraine in Kyiv, Fond 356.

The project is intended to support validation, text normalization, term-frequency analysis, document-frequency counts, chronological analysis, transparent thematic dictionaries, corpus comparison, and reproducible export of tables and visualizations.

The software is developed independently. Voyant Tools and other digital-humanities applications serve only as methodological reference points; their source code is not included in this project.

### Project status

The project is at an early development stage. The input schema, analytical modules, and methodology are still being designed. The repository does not yet contain a finished software release or complete archival datasets.

The MIT License applies to the software code only. Archival descriptions, document images, and other source datasets may have separate provenance and reuse conditions. A documented sample dataset is planned for testing and demonstration.
