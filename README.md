# Аналіз архівних описів — 0.8

Класифікація заголовків ДАМО, фонд 230, і ЦДІАК України, фонд 356.
Версія скрипта: `0.8`. Правила словників: `0.7-draft`.

## Запуск

1. Розпакуйте весь комплект в окрему папку.
2. Скопіюйте до неї свій `input.xlsx`.
3. Відкрийте цю папку в PyCharm із Python 3.12 та запустіть `fond_analysis.py`.

Потрібні ті самі бібліотеки: `openpyxl`, `PyYAML`, для графіків — `matplotlib`.
За потреби встановіть їх у вибраному інтерпретаторі:

```text
python -m pip install openpyxl pyyaml matplotlib
```

Вхідний файл не змінюється. Кожен запуск створює окрему папку `outputs/`.
Усі три Python-файли мають залишатися поруч.

## Що де знаходиться

| Файл або папка | Призначення |
|---|---|
| `fond_analysis.py` | Запуск, читання Excel, класифікація, перевірки, звіти та експорт |
| `text_matching.py` | Нормалізація, мовні правила та пошук слів і фраз |
| `models.py` | Структури запису, категорії та повідомлення перевірки |
| `config/analysis.yaml` | Вхідний файл, папка результатів, межі років та експорт |
| `config/sources.yaml` | Аркуші, архіви, фонди та мови |
| `config/categories.yaml` | Категорії, назви, макроблоки та шляхи словників |
| `dictionaries/` | Робочі правила 11 категорій двома мовами |
| `docs/` | Актуальні методичні пояснення й опис перевіреного спрощення |
| `tests/` | 19 автоматичних тестів |
| `reference-materials.zip` | Повні попередні словники, конфігурації, примітки, документація та історія змін |

У робочих словниках залишено поля, які читає класифікатор. Методичні
примітки, походження термінів і зіставлення з УДК збережено в архіві
`reference-materials.zip` за колишніми шляхами файлів.

## Результати

Збережено всі попередні типи результатів:

- тематичні XLSX/CSV, некласифіковані й службові записи;
- `tables/classification_index.csv` з категоріями, балами й поясненнями;
- статистику та детальні таблиці за джерелами й для об'єднаного корпусу;
- `description_summary.csv` з контрольними підсумками за кожним архівним описом;
- звіти, перевірки даних і графіки PNG/SVG;
- складені стовпчикові діаграми, де кожен стовпчик розкладено за описами,
  а легенда містить повні архівні посилання;
- `run_manifest.json` з версіями та контрольними сумами, включно з новими модулями.

Один заголовок може належати до кількох тем. Бали — ваги правил, не
ймовірності. `context_only` означає лише контекст, без предметної теми.

## Налаштування та перевірка

Редагуйте лише конфігурації в `config/`. Категорію можна вимкнути через
`enabled: false`. Ваги, списки слів і правила змінюються у відповідному
словнику; це вже зміна методики, а не технічне спрощення.

```text
python -m unittest discover -s tests -v
```

Зміни ревізії: [0.8](docs/revision-0.8.md).

Підсумок перевірки на корпусі користувача: `docs/simplification.md`.
Методика: `docs/dictionary_methodology.md`; експорт: `docs/export_methodology.md`;
особливості вхідних даних: `docs/input_export_notes.md`.

Повний комплект розраховано на звичайний запуск скрипта. Внутрішня функція
`load_dictionaries` тепер повертає чотири значення: категорії, неоднозначності,
макроблоки та версію; невикористаний результат зі стоп-словами прибрано.
