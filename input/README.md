# Вхідні книги

Покладіть сюди одну або кілька книг `.xlsx`. Скрипт опрацьовує кожну книгу
окремо, у порядку назв файлів. Тимчасові файли Excel `~$*.xlsx` ігноруються.

Кожний аркуш книги є одним описом. У клітинках A1:B3 обов’язково вкажіть:

| Рядок | Колонка A | Колонка B |
|---|---|---|
| 1 | `Архів` | назва архіву, наприклад `ДАМО` |
| 2 | `Фонд` | номер фонду, наприклад `230` |
| 3 | `Опис` | номер опису, наприклад `1` |

У четвертому рядку мають бути заголовки п’яти колонок: номер, заголовок
справи, крайні дати, кількість аркушів, примітки. У A4 має бути `№`.
Справи та структурні рядки починаються з рядка 5. Аркуші можуть мати довільні
назви; архів і шифр визначаються за A1:B3. Колонки A–E зберігаються у
тематичних XLSX; порожні значення дат, аркушів і приміток допустимі й
відображаються в перевірках якості.

Кілька описів одного фонду можна зберігати в одній книзі. Якщо одна
дослідницька добірка охоплює фонди різних архівів (наприклад, ДАМО, ф. 230,
і ЦДІАК України, ф. 356), розмістіть їх на окремих аркушах однієї книги:
скрипт видасть окремі звіти за архівними фондами й спільний звіт `combined`
для **цієї книги**. Інші книги з папки `input/` не додаються до її статистики.

Файли `.xlsx` у цій папці виключені з Git.
