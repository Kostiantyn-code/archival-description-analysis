# Ревізія 0.8

Спрощення перевіреної версії 0.7 зі збереженням результатів аналізу.

- Індексований пошук слів і фраз та повторне використання результатів зіставлення.
- Об'єднані повторювані цикли класифікації й запису таблиць.
- Нормалізація та пошук у `text_matching.py`, структури даних у `models.py`.
- Робочі YAML містять лише використовувані поля; довідкові матеріали й
  попередні конфігурації збережено у `reference-materials.zip`.
- Прибрано невикористане завантаження стоп-слів.
- Збережено всі типи вихідних таблиць, звітів, книг Excel і графіків.

Перевірка: 18 тестів; однакові результати для 12 444 справ і 102 вихідних
файлів з урахуванням очікуваних відмінностей службових метаданих.
У повторному вимірі класифікації на 1 464 заголовках прискорення — 4,54 раза.
Подробиці: [опис спрощення](simplification.md).

Версія програми — `0.8`. Версія правил словників залишається `0.7-draft`,
оскільки терміни, ваги та логіка присвоєння категорій не змінювалися.

Для запуску потрібні всі три Python-файли поруч. Внутрішня функція
`load_dictionaries()` повертає чотири значення замість п'яти: невикористаний
результат зі стоп-словами прибрано. Звичайний запуск через Run не змінився.
