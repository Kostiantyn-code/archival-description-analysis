# Перевірка доповнення візуалізації версії 0.8

Дата перевірки: 21.09.2026.

Базовий стан GitHub: коміт
`09af72ddc1332fee5f9b51b6a631a4cd36d5cdd8` —
«Ревізія 0.8: спрощення коду та словників зі збереженням результатів».

## Що змінено

- Діаграми `cases_by_decade`, `thematic_categories`,
  `classification_coverage` та `included_and_withdrawn` стали складеними:
  кожен стовпчик розкладено за архівними описами.
- Для ДАМО, ф. 230, описи 1–4 використано відтінки синього; для ЦДІАК
  України, ф. 356, опис 1 — окремий охристий колір.
- Легенди містять повні архівні посилання.
- Загальне значення має однозначний підпис `Усього: N`. Внутрішні числа
  виводяться лише для достатньо великих сегментів, тому вони не дублюють
  загальне значення на малих стовпчиках.
- Додано `description_summary.csv` для контролю кількості справ,
  класифікацій і вибулих записів за кожним описом.
- У джерельній конфігурації уточнено номер опису ЦДІАК: `1`.
- Запис службових CSV тепер перевіряє фактичну кількість створених рядків.

Тематичні словники, ваги, пороги та правила класифікації не змінювалися.
Теплова карта `themes_by_decade` також залишилася без змін.
