# Усунення дублювання після 0.14-dev

База: `caf8bee`, після злиття PR №11. Перевірка: 29 вересня 2026 року.

## Знайдено та спрощено

- Три реалізації запису CSV об’єднано в `report_utils.write_csv`.
  Збережено UTF-8 BOM, роздільник `;`, порядок колонок і рядків,
  роботу з генераторами, підрахунок записаних рядків. Для термінології
  та мережі збережено сувору перевірку зайвих полів і вимогу наявного каталогу;
  головний експортер, як і раніше, створює каталог та ігнорує зайві поля.
- Три реалізації безпечного JSON для HTML використовують
  `report_utils.json_for_script`. Символ `<` екранується, щоб заголовок
  справи не міг закрити елемент `script`.
- Сім повторів формули ідентифікатора справи замінено властивістю
  `Record.record_uid`. Вона обчислюється з джерела, аркуша й фізичного рядка;
  поля dataclass та формати CSV/JSON не змінено.
- Два однотипні блоки експорту класифікованого реєстру та справ без теми
  об’єднано в цикл зі збереженням повідомлень перевірки кількості рядків.
- Дубль форматування цілих чисел у Markdown-звіті замінено на наявну
  `format_count`.
- Прибрано 13 невикористаних імпортів із головного модуля та повторені
  літерали `иями` і `ие` у множині російських закінчень. Склад множини,
  порядок відсортованих закінчень і правила класифікації залишилися тими самими.
- Спільний модуль включено до контрольних сум маніфесту.

## Файли та межі очищення

Побайтово однакових відстежуваних файлів не знайдено. Активні модулі,
три HTML-шаблони, карта, словники й конфігурації використовуються програмою.
Документація описує методику або історичні перевірки.
`reference-materials.zip` містить 45 історичних матеріалів і явно згаданий
у README та попередньому звіті про спрощення; це не тимчасовий результат запуску.
Тому робочі й історичні файли не видалялися лише через відсутність імпорту Python.

Прямий пошук `contains_item` збережено: він є незалежним еталоном для
перевірки індексованого пошуку. Візуально схожі CSS/JavaScript у шаблонах
також збережено, щоб звіти залишалися автономними й не отримали зайвої
залежності від спільного зовнішнього ресурсу.
