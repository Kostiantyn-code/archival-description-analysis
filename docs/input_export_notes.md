Повідомлений Google час зміни перед читанням: 2026-09-08T13:16:34.302Z.
Прочитано актуальні значення A:G усіх п'яти аркушів через авторизоване підключення.

input.xlsx — окрема робоча копія значень, а не архівна копія всіх властивостей
Google Sheets: коментарі, історія змін, права, формули та первинне оформлення
не відтворюються. Позиції змістовних рядків і назви аркушів збережено;
порожній хвіст сітки скорочено. Вихідна Google-таблиця не редагувалася.

Технічні зміни при перенесенні:

1. Переноси CRLF у текстових клітинках приведено до LF засобами XLSX/XML.
2. ЦДІАК, клітинка B375, справа № 347: вилучено один недопустимий для XML
   символ U+FFFE між фрагментами «Зпатополь» і «ская». Інші літери, зокрема
   імовірну помилку в самому прізвищі, не виправляли.
3. Точні прочитані значення збережені в `source_values.json`, включно з U+FFFE
   та первісними переносами. Цей файл забезпечує контроль технічної нормалізації.

Після запису зіставлено всі перенесені клітинки A:G з актуальним джерелом:
неочікуваних відмінностей після врахування перелічених технічних змін немає.
Числові значення і текстові номери збережені; формат 1.0/1 не змінює значення.

Поля *_raw у CSV успадковують поведінку 0.5: крайні пробіли й переноси
обрізаються через strip(). Для дослівного відтворення клітинки використовуйте
input.xlsx або source_values.json, а не CSV.
