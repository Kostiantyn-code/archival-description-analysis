# Аналіз архівних описів фонду 230

Версія скрипта і словників: `0.5-draft`  
Корпус: аркуші `Опис 1`–`Опис 4` файла фонду 230  
Контрольний обсяг: 11 980 заголовків справ

## Що змінено у 0.5-draft

Класифікацію поділено на два рівні:

1. **Предметна тема** — про що саме справа.
2. **Контекстна згадка** — яка особа, установа, посада чи слабка
   лексична ознака згадується в заголовку.

Слова `купець`, `міщанин`, `чиновник`, `канцелярія` або `поліція` більше не надають
тему автоматично. Вони зберігаються як контекст і стають предметною ознакою лише у
змістовному поєднанні з іншими словами.

Додатково:

- розріджені позначки `В И Б У Л А`, `В И Б У Л И`, `В И Б У Л О` розпізнаються
  як вибулі записи;
- загальні заголовки груп справ без номера не вважаються помилками;
- програма виводить прогрес класифікації і орієнтовний час до завершення;
- окремі CSV фіксують предметні теми, лише контекстні згадки та випадки без
  жодної ознаки.

## Запуск у PyCharm

1. Покладіть `fond_analysis.py`, папку `dictionaries` і `input.xlsx` в одну папку.
2. Запустіть `fond_analysis.py` у PyCharm Community Edition.
3. Програма створить або оновить папки `reports`, `figures` і `work`.

Вхідний XLSX не змінюється.

## Структура словника

- `strong_phrases` — сталі словосполучення, достатні для присвоєння теми;
- `strong_terms` — відносно однозначні терміни;
- `context_only_phrases` і `context_only_terms` — назви установ, посад та статусів, які самі
  по собі не визначають тему;
- `contextual_terms` — слабкі ознаки, що набирають лише один бал;
- `context_rules` — поєднання ознак, які разом підтверджують тему;
- `exclude_phrases` — сталі вислови, що блокують помилкове тлумачення;
- `review_terms` — неоднозначні ознаки для ручного контролю.

Ваги: 4 бали за сильне словосполучення, 3 бали за сильний термін, 1 бал за
контекстну ознаку та 3 бали за виконане контекстне правило. Мінімальний поріг —
3 бали. Один заголовок може отримати кілька тем.

## Результат контрольного прогону

На 11 980 заголовках версія `0.5-draft` дала такий баланс:

- предметну тему визначено для 8 334 заголовків (69,57%);
- лише контекстні ознаки — для 3 523 (29,41%);
- ні предметної теми, ні контексту — для 123 (1,03%);
- кілька предметних тем — для 2 484 заголовків (20,73%).

Ці відсотки описують словникове покриття, а не точність. Для оцінки точності потрібна
окрема ручна валідація вибірки.
