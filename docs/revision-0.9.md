# Ревізія 0.9

Версія 0.9 додає окремий річний хронологічний звіт, не змінюючи наявний
розподіл `cases_by_decade`.

## Нові результати

- `tables/cases_by_year.csv` — одна колонка року та окремі колонки для
  кожного аркуша-опису;
- `figures/cases_by_year.png` і `figures/cases_by_year.svg` — вертикальні
  панелі з окремим хронологічним рядом для кожного опису та спільною шкалою
  років.

У каталозі `combined` графік містить п'ять рядів: чотири описи ДАМО,
ф. 230, і опис ЦДІАК України, ф. 356. Вони не підсумовуються в один ряд.

## Методика підрахунку

Справу з діапазоном дат зараховано до кожного року в межах діапазону. Якщо
поле дат порожнє, але справа розташована під однозначним заголовком року,
використано рік цього заголовка. Некоректні дати не включаються. Для захисту
від помилково розпізнаних надто довгих інтервалів параметр
`chronology.maximum_span_years` обмежує розгортання діапазону; у такому разі
враховується лише початковий рік.

Наявні файли `cases_by_decade.csv`, `cases_by_decade.png` і
`cases_by_decade.svg` та їхня методика не змінені.
