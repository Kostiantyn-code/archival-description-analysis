# Методика формування класифікаційних словників

## Джерельна основа

1. Українські скорочені таблиці Універсальної десяткової класифікації, підготовлені за участю Книжкової палати України та оприлюднені Консорціумом УДК: <https://www.udcsummary.info/php/index.php?lang=uk&pr=Y>.
2. Матеріали Книжкової палати України про скорочені таблиці УДК: <https://www.ukrbook.net/UDC_n/UDC/UDC_skoroch_table.html>.
3. Корпус заголовків справ фонду 230: аркуші `Опис 1`–`Опис 4`, 12 003 заголовки справ, включені до аналізу.
4. Корпусна вибірка для уточнення: 2 690 заголовків, тематику яких не визначила версія словників `0.2-draft`.

## Принцип побудови

УДК використано як нормативний каркас тематичних понять, а не як готовий список слів для автоматичної класифікації. Термінологічне наповнення адаптовано до заголовків архівних справ ХІХ століття.

Система має два рівні:

1. макроблоки, які відповідають структурі дисертації;
2. конкретні тематичні категорії.

Класифікація багатозначна: один заголовок може одночасно належати до кількох категорій.

## Спостереження за корпусом

Попередній перегляд виявив характерні для фонду конструкції: `міська поліція`, `стягнення приватного боргу`, `сирітський суд`, `квартирна комісія`, `губернське правління`, `політична благонадійність`, `навчальний округ`, `медичний департамент`.

Виявлено слова, які не можна класифікувати за простим збігом фрагмента:

- `освітлення` не пов’язане з категорією освіти;
- `судно` не є словоформою слова `суд`;
- `метрична книга` не є культурною тематикою лише через слово `книга`;
- `духовний заповіт` не слід автоматично відносити до релігії;
- `команда`, `порт`, `нагляд`, `товариство` потребують контексту.

Під час другого проходу виявлено, що значну частину пропусків спричиняла не відсутність поняття у словнику, а неправильне зіставлення відмінкових форм. Зокрема, форми `губернське` / `губернського`, `сирітський` / `сирітського`, `дума` / `думою` мають зіставлятися як одне поняття. Морфологічну нормалізацію виправлено зі збереженням повного оригінального заголовка.

Нові терміни добиралися за частотністю у некласифікованому корпусі, але включалися лише після перегляду контекстів. Перевага надавалася сталим словосполученням (`приміська дума`, `військово-судова справа`, `відкупне утримання`, `морехідний клас`) і контекстним правилам. Загальні слова на зразок `документи`, `відомості`, `листування`, `надання` не використовуються як самостійні тематичні маркери.

## Подальша перевірка

Перед остаточним використанням необхідно:

1. виконати пробну класифікацію всього корпусу;
2. сформувати не менше 50 випадків із кожної категорії або всі випадки для малих категорій;
3. перевірити хибні позитивні й хибні негативні спрацьовування;
4. скоригувати словники та зафіксувати версію;
5. подати в методичному описі версію словників, дату й частку перевіреної вибірки.
