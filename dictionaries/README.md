# Робочі словники

12 категорій, кожна має українську й російську версію. Перелік категорій,
підписи, назви експортованих книг і шляхи файлів задає `config/categories.yaml`.

| Поле | Як використовується |
|---|---|
| `id`, `macroblock` | Ідентифікатор категорії та макроблок |
| `minimum_score` | Поріг присвоєння теми; за відсутності береться з конфігурації |
| `strong_phrases` | Збіг фрази: 4 бали |
| `strong_terms` | Збіг терміна: 3 бали |
| `contextual_terms` | Слабкий контекст: 1 бал і контекстна мітка |
| `context_only_terms`, `context_only_phrases` | Лише контекстна мітка, без балів |
| `context_rules` | Співнаявність усіх `all` і принаймні одного `any`, якщо задані; вага `score` |
| `exclude_phrases` | Маскування фраз перед перевіркою категорії |
| `review_terms` | Позначення випадків поблизу порога для ручної перевірки |

`auxiliary/ambiguities.yaml` та його RU-версія задають міжкатегоріальні
обмеження й контекстні умови. Ці файли беруть участь у класифікації.

Списки правил і їх порядок збережені. Не видаляйте схожі словоформи
автоматично: у поточній методиці вони можуть окремо додавати бали.
Різницю між поведінкою слабких ознак UK і RU також збережено.

Пояснення походження, зіставлення з УДК, попередні версії та стоп-слова
збережено у `reference-materials.zip` у корені комплекту. Стоп-слова
не застосовувалися до класифікації; частотний аналіз скрипт не виконує.
Докладна методика — `docs/dictionary_methodology.md`.
